# InternPilot 求职准备交互原型

本原型用五步路径串联学生求职准备：

1. 设定目标，收藏多个具体岗位，查看带来源的要求汇总。
2. 按要求核对个人经历，并在经历库中新增、修改、复用经历。
3. 查看多项计划建议，修改任务内容、步骤、时间与产出，选择采纳或不采纳。
4. 在“执行计划”推进已采纳任务，勾选步骤并保存真实成果。
5. 记录岗位申请状态与反馈，再重新核对并生成下一轮建议。

## 运行

`dist/` 是无需构建的静态站点。在该目录启动静态 HTTP 服务即可预览。

## 原型边界

- 岗位数据为演示内容。可手动输入岗位及要求，但原型不会连接招聘平台。
- 要求归纳与计划建议由本地规则模拟，用于验证产品流程，不是真实 AI 分析。
- 用户输入仅保存在当前浏览器的 `localStorage` 中；清除站点数据或使用“重置体验”会清空记录。
- 收藏不等于投递；投递、面试与反馈状态都由用户手动记录。
