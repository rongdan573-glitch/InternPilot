# InternPilot 求职准备交互原型

本原型用五步路径串联学生求职准备：

1. 设定目标，收藏多个具体岗位；可粘贴 JD 原文、保存来源与旧版，筛选、优先推进或归档岗位。
2. 可先保留个人材料原文，再建立并核对经历草稿；按岗位要求关联、修改和复用经历。
3. 查看多项计划建议，修改任务内容、步骤、时间与产出，选择采纳或不采纳。
4. 在“执行计划”推进已采纳任务，勾选步骤并保存真实成果。
5. 为优先岗位编辑并保存沟通草稿版本；本人在招聘平台投递后，记录实际日期、状态与反馈，再进入下一轮建议。

## 运行

`dist/` 是无需构建的静态站点。在该目录启动静态 HTTP 服务即可预览。

## 原型边界

- 内置岗位为演示内容。可手动输入岗位、来源、JD 原文与要求，但原型不会读取招聘平台链接。
- 要求归纳与计划建议由本地规则模拟，用于验证产品流程，不是真实 AI 分析。
- 用户输入仅保存在当前浏览器的 `localStorage` 中；清除站点数据或使用“重置体验”会清空记录。
- 收藏和优先推进均不等于投递；草稿不会自动发送，投递、面试与反馈状态都由用户确认并手动记录。
